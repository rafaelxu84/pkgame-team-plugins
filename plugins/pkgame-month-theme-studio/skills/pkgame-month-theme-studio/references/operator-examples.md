# Operator examples

Accept natural-language requests in any language. Reuse supplied details and ask only about missing essentials. These examples do not define fixed placements or ratios.

## Image

```text
$pkgame-month-theme-studio
Create an image, ratio 3:1, width 1800px.
Theme: weekend football. Include a football, boots and stadium lights.
Use the default style and colors. No text or logo. Make one version.
```

Effective canvas: 1800 x 600px. No additional placement question is needed.

## Icon

```text
$pkgame-month-theme-studio
Create an icon for a reward chest. Include a chest and chips.
Use the current style, with fewer small details.
```

State the default 1024 x 1024 transparent PNG and proceed with one version. Do not add a person, landmark, gems, or logo from unrelated references.

## Style and brand override

```text
$pkgame-month-theme-studio
Create an image, 2:1, width 1600px. Theme: music night.
Include headphones and a stage. This time use a flatter comic treatment
with emerald and warm white. Add the attached sponsor logo at the top left.
No text. Make two variants.
```

Use the requested 1600 x 800px canvas, style, colors and logo. The bundled pink/cyan poster direction does not override the current request. Shared defaults remain unchanged.

## Missing essentials

```text
$pkgame-month-theme-studio
Make an image for a new campaign.
```

Ask one bundled question for aspect ratio, width in pixels, campaign theme, and main elements. Do not ask for a specific site placement or offer mandatory subject categories.

## Revision and defaults

```text
Keep the subject and dimensions. Make this version lighter and remove the logo.
```

Revise this task only. Keep other approved choices.

```text
Update the shared default theme to this new palette and these references.
```

Update the theme snapshot and version when authorized, preserve the generic workflow, and provide a new portable package. Do not claim teammates' copies updated automatically.
